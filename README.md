# Fardin Portfolio Website

This is a beginner-friendly HTML/CSS/JavaScript portfolio based on the purple/black Figma concept.

## Folder structure

```text
fardin-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    └── profile.jpg   <-- add your own photo here
```

## What you need

You do NOT need C++, Java, React, or anything complicated for version 1.

Use:
- HTML = website structure
- CSS = design, purple/black theme, hover glow, responsive layout
- JavaScript = small interactions such as the mobile menu and active navigation
- GitHub = stores your code
- GitHub Pages = publishes the website

## First things to replace

1. Put your portrait at `assets/profile.jpg`.
2. Replace the four portfolio placeholders with your real project thumbnails.
3. Replace the `href="#"` values on project cards with your actual video links.
4. Replace the social links with your real Facebook / Instagram / LinkedIn / WhatsApp URLs.
5. Adjust the text in `index.html` to match your actual experience and services.

## Run it on your computer

The easiest beginner method:

1. Open the project folder.
2. Double-click `index.html`.
3. It opens in your browser.
4. Edit `index.html` or `style.css`.
5. Refresh the browser to see your changes.

For a nicer workflow, install VS Code and use the Live Server extension.

## Publish with GitHub Pages

1. Create a GitHub account.
2. Create a new repository, for example `fardin-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
4. Open the repository's **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Select the `main` branch and the root folder.
7. Save.
8. GitHub will give you a public website URL.

## Important

Do not paste your website code into a C++ or Java project. This website is a normal front-end website, so HTML/CSS/JavaScript are enough for the first version.
